# Конвертер температур (C / F / K)

Консольное приложение на Python для конвертации температур между шкалами
Цельсия, Фаренгейта и Кельвина с сохранением и просмотром истории.

## Возможности

- Конвертация между любыми парами шкал C / F / K.
- Нумерованные меню — исключают опечатки при вводе шкал.
- Ввод числа с точкой **или запятой** (`36.6` и `36,6` эквивалентны).
- Валидация: пустой ввод, нечисло, `NaN`, `inf`, значения ниже абсолютного нуля.
- История конвертаций в текстовом CSV (`history.csv` рядом с `main.py`).
- Просмотр истории прямо из программы.
- Предупреждение при выборе одинаковых исходной и целевой шкал.
- Аккуратный выход по `Ctrl+C` / `Ctrl+D` — без traceback.
- Соблюдение PEP 8, аннотации типов, докстринги на русском.

## Требования

- Python **>= 3.10**
- Windows 10 (проверено), Linux/macOS — должны работать без изменений
- Сторонних зависимостей нет — только стандартная библиотека
